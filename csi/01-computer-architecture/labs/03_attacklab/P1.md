sub $0x28, %rsp move the stack pointer towards lower address by (2*16+8 = 40 bytes)
byte offset 28
A8 + 28 = D0
mov    %rsp,%rdi
Hands %rsp (the start of our 40-byte buffer on the stack) to Gets as the destination pointer where your typed input will be stored. 401a40 is simply where the code of Gets lives in memory.

x86-64 use little endian
